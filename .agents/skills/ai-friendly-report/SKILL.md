# AI 친화적 행정 보고서 작성

## 1. 언제 쓰는지
- 사람과 AI가 모두 명확히 이해할 수 있는 행정 보고서를 새로 작성할 때 사용한다. [출처: 2. 주요내용 > 가. 기본방향]
- 기존 행정 보고서를 내용 중심의 문서로 다듬을 때 사용한다. [출처: 2. 주요내용 > 가. 기본방향]
- 보고서의 최종 산출물은 HWPX로 만들며, Markdown 원고는 제작 과정의 중간 파일로만 사용한다. [출처: 사용자 운영규칙]

## 2. 순서
1. 형식적인 꾸미기보다 내용을 중심에 두고, 불필요한 문서 작업을 최소화하여 작성한다. [출처: 2. 주요내용 > 가. 기본방향]
2. 주어와 서술어를 명확히 갖춘 서술식 문장으로 작성하고, 주어나 서술어가 생략된 개조식은 지양한다. 문서 앞부분에는 전체 내용을 한눈에 파악할 수 있는 요약을 반드시 추가한다. [출처: 2. 주요내용 > 나. 세부내용 > 서술방식]
3. 가이드라인 적용 예시를 따라 기본 글머리 위계를 `1. → 가. → ○ → -`로 구성한다. 문서 구조상 다른 구분이 필요한 경우에만 번호항목(Ⅰ., 1., 가., 1), 가), (1), (가), ①, ㉮)과 특수기호(□, ○, -, ·)를 혼합하여 사용한다. [출처: <별첨> 문서 작성 예시(가이드라인 적용)의 1./가./○/- 위계; 2. 주요내용 > 나. 세부내용 > 항목표시]
4. 글머리 특수기호는 모양이 비슷한 다른 문자가 아니라 유니코드 문자표의 해당 문자를 직접 입력한다. 특히 본문 글머리는 한글 자모 `ㅇ`이 아닌 원 문자 `○`를 사용한다. [출처: 2. 주요내용 > 나. 세부내용 > 항목표시]
5. 보고서의 기본 글꼴은 HWPX에 등록된 정확한 글꼴명인 `함초롬바탕`으로 설정한다. 가이드라인 별첨의 실제 서식값에 따라 본문과 본문 강조는 15pt, 요약문은 12pt로 설정하며, 별도의 서식 요구가 없으면 제목·표 등을 포함한 새 보고서에 다른 글꼴을 임의로 혼용하지 않는다. [출처: <별첨> 문서 작성 예시(가이드라인 적용)의 HWPX 글꼴 속성(본문·본문 강조: 함초롬바탕 15pt, 요약문: 함초롬바탕 12pt); 사용자 운영규칙]
6. 자간 0%, 장평 100%, 문단 위 간격 10pt, 줄 간격 150%로 설정한다. [출처: 2. 주요내용 > 나. 세부내용 > 편집 및 서식]
7. 표는 단순 구조로 만들고, 차트·조직도(표 형태 조직도 포함)·인포그래픽은 필요한 경우에만 사용한다. 그림을 사용하면 그 설명을 문서 본문에 반드시 포함한다. [출처: 2. 주요내용 > 나. 세부내용 > 표; 그림]
8. 작성과 검토를 마친 보고서는 `.hwpx` 파일로 저장하여 최종 산출물로 제공한다. [출처: 사용자 운영규칙]

## 3. 끝나는 조건
- 문서 앞부분에 전체 내용을 한눈에 파악할 수 있는 요약이 있다. [출처: 2. 주요내용 > 나. 세부내용 > 서술방식]
- 본문 문장이 주어와 서술어를 명확히 갖춘 서술식으로 작성되어 있다. [출처: 2. 주요내용 > 나. 세부내용 > 서술방식]
- 사용한 글머리 단계가 기본 위계 `1. → 가. → ○ → -`와 일치하고, 다른 번호나 기호를 섞었다면 문서 구조상 필요한 경우에 해당한다. [출처: <별첨> 문서 작성 예시(가이드라인 적용)의 1./가./○/- 위계; 2. 주요내용 > 나. 세부내용 > 항목표시]
- HWPX의 실제 글꼴 속성을 확인했을 때 본문과 본문 강조는 `함초롬바탕` 15pt, 요약문은 `함초롬바탕` 12pt이며, 새로 작성한 제목·표 등에 다른 글꼴이 임의로 섞이지 않았다. [출처: <별첨> 문서 작성 예시(가이드라인 적용)의 HWPX 글꼴 속성; 사용자 운영규칙]
- 항목 구분에 쓴 특수기호가 유니코드 문자이고 본문 글머리가 `○`이며, 자간 0%·장평 100%·문단 위 10pt·줄 간격 150%가 적용되어 있다. [출처: 2. 주요내용 > 나. 세부내용 > 항목표시; 편집 및 서식]
- 모든 표가 단순 구조이고, 사용한 모든 그림에 대한 설명이 본문에 있다. [출처: 2. 주요내용 > 나. 세부내용 > 표; 그림]
- 최종 보고서가 HWPX 파일로 존재하며 사용자에게 HWPX 파일을 제공할 수 있다. [출처: 사용자 운영규칙]

## 4. 하지 말 것
- 주어나 서술어가 생략된 개조식을 기본 서술방식으로 삼지 않는다. [출처: 2. 주요내용 > 나. 세부내용 > 서술방식]
- 문서 분량을 억지로 맞추기 위한 불필요한 편집을 하지 않는다. [출처: 2. 주요내용 > 나. 세부내용 > 편집 및 서식]
- 셀 병합 표, 표 안에 표가 들어간 표, 대각선이 들어간 표, 시각적 강조를 위한 특수 표를 사용하지 않는다. [출처: 2. 주요내용 > 나. 세부내용 > 표]
- 설명 없이 차트·조직도·인포그래픽 등 그림만 넣지 않는다. [출처: 2. 주요내용 > 나. 세부내용 > 그림]
- `한컴돋움`, `휴먼명조` 등 가이드라인의 본문 서식과 다른 글꼴을 임의로 적용하거나 혼용하지 않는다. [출처: <별첨> 문서 작성 예시(가이드라인 적용)의 HWPX 글꼴 속성; 사용자 운영규칙]
- 보고서 요청에 Markdown 원고만 제공하고 작업을 끝내지 않는다. [출처: 사용자 운영규칙]
