# 배분규칙 추가·수정

> 사용법: 한 번 손으로 해 본 작업의 순서를 아래 4칸에 채워 저장합니다.
> 저장 위치: `.agents/skills/<스킬 이름>/SKILL.md` (이 양식 폴더는 그대로 두고 복사해서 씀)
> 다음부터는 "배분규칙 추가·수정 스킬대로 해 줘" 한 줄로 같은 순서를 반복합니다.

## 1. 언제 쓰는지
- `data/배분기준표_소관키워드_304건.csv`의 키워드, 제외어, 우선순위 또는 배분 과를 추가·수정하라는 요청에 사용한다.
- 입력으로 변경할 키워드와 과, 우선순위, 필요하면 제외어가 주어지며 `data/A부_조직도_26개과.csv`, `web/engine.js`, `test_engine.js`로 유효성과 결과를 확인한다.

## 2. 순서
1. 배분기준표에서 요청한 키워드의 기존 규칙을 찾고 현재 과·제외어·우선순위를 확인한다.
2. 조직도에서 대상 과가 실제로 존재하는지 확인하고, 기존 규칙 수정인지 새 규칙 추가인지 구분한다.
3. 배분기준표의 해당 행만 수정한다. 새 규칙이면 중복되지 않는 `rule_id`를 사용하고 기존 열 순서를 유지한다.
4. `node test_engine.js`를 실행해 `1순위 정답 n/40 · 3순위 안 m/40`과 틀린 문항 표를 확인한다.
5. 변경한 규칙의 최종 값과 시험 전후 결과를 사용자에게 보고한다.

## 3. 끝나는 조건
- 요청한 모든 키워드의 과·제외어·우선순위가 배분기준표에 정확히 반영되어 있다.
- 대상 과가 조직도에 존재하고, 배분기준표의 열 구조와 전체 규칙 데이터가 정상적으로 유지되어 있다.
- `node test_engine.js`가 오류 없이 끝나며 40건 기준의 1순위·3순위 결과와 오답 목록이 출력된다.

## 4. 하지 말 것
- 사용자가 요청하지 않은 규칙, 조직도, 시험 정답 데이터를 함께 수정하지 않는다.
- 규칙을 `web/engine.js`에 하드코딩하거나 CSV와 다른 예외 로직을 임의로 추가하지 않는다.
- 조직도에 없는 과를 만들거나 근거 없이 키워드·제외어·우선순위를 추정하지 않는다.
- 정확도를 높이기 위해 `data/시험_요구문항_40건.csv`의 정답이나 요구내용을 바꾸지 않는다.
